# MY_TRIP

숙소 검색과 예약, 여행지 추천, 리뷰와 결제를 한곳에서 제공하는 Java 기반 여행 서비스입니다.

## 주요 기능

- 지역별 숙소·객실 검색과 가격 조회
- 예약, 쿠폰, 결제 및 환불 처리
- 여행지와 행사 정보 조회
- 리뷰, 댓글, 좋아요와 신고 기능
- 판매자용 객실 관리와 관리자 기능
- 카카오·네이버 소셜 로그인

## 코드 구성

```text
controller/  요청 처리와 화면 이동
service/     예약·결제·외부 API 연동 로직
dao/         데이터 접근 인터페이스
mapper/      MyBatis SQL 매퍼
resources/   정적 자원
```

이 저장소는 프로젝트의 Java 소스와 MyBatis 매퍼를 정리한 아카이브입니다. 원래 실행 환경의 공통 모듈과 설정 파일이 포함되어 있지 않아 현재 저장소만으로는 바로 실행되지 않습니다.

## 환경 변수

소셜 로그인 기능에는 다음 환경 변수가 필요합니다. 실제 값은 저장소에 커밋하지 않습니다.

```text
KAKAO_CLIENT_ID
NAVER_CLIENT_ID
NAVER_CLIENT_SECRET
```

`.env.example`에는 변수 이름과 예시 값만 두고, 발급받은 값은 로컬 또는 배포 환경에서 주입합니다.

## 보안 메모

과거 커밋에 인증값이 포함되었을 수 있으므로 각 개발자 콘솔에서 기존 키를 폐기하고 새 키를 발급해야 합니다. 현재 파일에서 값을 지워도 이전 커밋에는 남아 있을 수 있습니다.
